# 월간 인시 통합 도구

출고계획현황 · 전체출고현황 · 세부현황(순번별 파일)을 넣으면 순번으로 자동 매칭하고, 공장·구분·작업장별 인시와 ±기준 저해품목을 정리한 엑셀을 만들어 주는 오프라인 HTML 도구입니다.

## 사용법
1. 배포된 웹 주소로 접속하거나, `index.html`을 크롬/엣지로 엽니다 (설치 불필요, 파일로 열면 인터넷도 불필요).
2. 출고계획현황, 전체출고현황 파일과 세부현황 폴더(파일 이름 = 순번, 예: `123.xlsx`)를 넣습니다.
3. **통합 실행** → 매칭 결과 확인 → **엑셀 내려받기**

## 파일
| 경로 | 설명 |
|---|---|
| `index.html` | 도구 본체 (단일 파일, 정적 웹앱) |
| `PRD_월간인시_통합도구.md` | 기획 문서 (PRD) |
| `가상데이터/` | 테스트용 가상 데이터 (실제 데이터 아님, 200품목) |
